{# Shared caveats for the Total Cost column. Included by every leaderboard that shows it. #}

Costs are currently calculated without accounting for caching benefits.

Known issue (October 5, 2026): Reported costs and token counts are overstated. Nested trace spans counted the same API response twice, so affected models are inflated by exactly 2×. Models logged as a single span are unaffected, so the overstatement is not uniform across rows. Not yet re-derived.
